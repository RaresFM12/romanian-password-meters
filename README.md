# How Well Do Password Strength Meters Work for Romanian Passwords?

Research project evaluating password strength meters (zxcvbn-ts) on Romanian passwords:
diacritics (ă â î ș ț) and their encoding variants, Romanian dictionaries, and
whether the existing `@zxcvbn-ts/language-ro` package improves accuracy.

## Structure
- `docs/research-plan.md`: the full research plan
- `scripts/preliminary/`: preliminary measurements on `language-ro` (see its README)

## Status
In progress (university research project, 2026).
